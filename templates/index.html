Settings & data

Bring your own airport database and enable optional cloud integrations.

Airport database

The included airports.dat is a small offline starter sample. Upload the full OpenFlights airports.dat to enable worldwide random selection. For permanent Render deployment, commit the file into data/airports.dat in GitHub.

Cloud integrations

Set OPENAI_API_KEY in Render environment variables to enable AI dispatch. You can optionally set OPENAI_MODEL. API calls are billed separately by OpenAI and are not required for the rest of the application.

SimBrief opens in its official website for flight-plan creation; a full authenticated SimBrief OFP import is not included in this first build. VATSIM uses its public current-flight feed.

Data and deployment

Important: Render Free uses an ephemeral filesystem. Logbook entries, missions and airport uploads stored in SQLite may disappear when the service restarts or redeploys. Export your logbook frequently. A persistent cloud database is required for reliable long-term storage.
